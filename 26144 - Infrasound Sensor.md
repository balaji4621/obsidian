# 📡 PS ID 26144: High-Sensitivity Microbarometer Infrasound Sensor
**Sponsoring Organization:** National Technical Research Organisation (NTRO)  
**Category:** Hardware  
**Theme:** Miscellaneous / Precision Sensors  

---

## 🎯 Project Overview
Infrasound sensors measure low-frequency atmospheric pressure waves ($< 20\text{ Hz}$) generated by volcanic eruptions, meteors, rocket launches, and industrial explosions. Designing this sensor requires custom hardware transduction rather than using standard off-the-shelf modules.

---

## 🏗️ Hardware Architecture & Component Roadmap

### 1. Sensing Mechanism (Ground-Up Transduction)
- **Primary Element:** Differential acoustic chamber with a flexible piezoresistive nanocomposite or capacitive diaphragm.
- **Acoustic Filtering:** Micro-machined capillary capillary/capillary port for static barometric pressure equalization ($< 0.01\text{ Hz}$ high-pass response).

### 2. Analog Front-End (AFE) Signal Conditioning
- **Amplification:** Ultra-low-noise instrumental amplifier (INA128 / AD8421) with sub-nV/$\sqrt{\text{Hz}}$ voltage noise.
- **Filtering:** 4th-order active Butterworth low-pass filter ($f_c = 20\text{ Hz}$) to reject ambient audio noise.
- **Thermal Compensation:** Monolithic Wheatstone bridge arrangement with integrated PT100/NTC thermal tracking.

### 3. Digitization & Embedded Processing
- **ADC:** 24-bit Delta-Sigma ADC (ADS1256 / ADS1220) for high dynamic range ($> 110\text{ dB}$).
- **Microcontroller:** ESP32 / STM32F4 for real-time digital filtering, FFT spectral analysis, and telemetry dispatch.

## 📊 Feasibility Analysis

- **Technical Feasibility:** **8.5 / 10** (High) — Achievable using low-noise instrumentation amplifiers, active analog low-pass filtering ($f_c = 20\text{ Hz}$), and 24-bit ADC readout.
- **Hackathon Timeline Feasibility:** **9.0 / 10** — A functional prototype with live infrasound FFT waveform streaming can be built within a 36-hour hackathon window using an analog breadboard/breakout setup before final PCB integration.
- **Key Risk & Mitigation:** Thermal drift and 1/f noise at $<1\text{ Hz}$ $\rightarrow$ Mitigated using a differential Wheatstone bridge topology and low-pass capillary pressure equalization.
